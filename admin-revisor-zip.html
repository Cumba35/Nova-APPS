Inventario de archivos

    2. Revisar todo el proyecto

    La herramienta recorre los archivos del ZIP, lee archivos de texto compatibles, divide el código en bloques para enviarlo a Nova IA y reúne los resultados.

    Qué comprobará la revisión:

    • Errores de lógica y posibles defectos del código.
    • Problemas de seguridad, autenticación y autorización.
    • Credenciales o secretos potencialmente expuestos.
    • Referencias a archivos, módulos, funciones y dependencias.
    • Posibles incompatibilidades entre archivos y componentes.
    • Configuración, estructura y mantenibilidad.
    • Pruebas recomendadas.

    Los archivos binarios, los archivos de texto demasiado grandes y otros archivos no compatibles pueden quedar fuera. No se garantiza detectar todos los errores.

    5. Límites y funcionamiento

    • El ZIP se lee en el navegador; no se ejecutan sus archivos.
    • Límite del ZIP: 25 MB y 1.000 archivos.
    • Límite de código legible: 200.000 caracteres.
    • Límite por archivo de texto: 500 KB.
    • Se requiere conexión y que la función Supabase nova-ia esté disponible.
    • El informe no demuestra que el proyecto compile, funcione o sea seguro.
    • Esta página no modifica ni publica archivos automáticamente en GitHub.
